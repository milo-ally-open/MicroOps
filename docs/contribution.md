# 贡献约定

1. 先阅读算子的 `docs/proposal.md`、`docs/spec.md` 和 `docs/tasks.md`，让实现与接口一致。
2. CPU 参考实现定义通用语义；新增设备实现时保持输入、输出、边界和精度约定一致。
3. 后端开关必须独立，默认关闭；CPU-only 配置不能要求设备 SDK。
4. 未在目标工具链和设备验证的后端应标注 scaffold 或未验证状态。测试被跳过时记录原因，不把跳过写成通过。
5. benchmark 仅提交真实运行记录，并保留设备、输入规模、编译器/运行时和原始测量信息。空白结果不填猜测值。
6. 每个算子的说明文档放入该算子的 `docs/`。动画只提交场景源码和必要素材，生成视频留在忽略的输出目录。
7. 提交前运行 `python tools/test.py --backend cpu`；工具链可用时再单独验证相关后端。
8. 不在没有明确许可的情况下为仓库添加许可证。
