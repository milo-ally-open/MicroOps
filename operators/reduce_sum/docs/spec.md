# reduce_sum 规格

## 定义

给定连续的一维 float32 输入 `x` 和元素数 `n`，返回：

`y = sum(x[i], i = 0..n-1)`

输出是一个 float32 标量。输入不要求特定对齐，但有效元素必须可读。

## 输入与输出

- `x`: 指向连续 float32 元素的指针。
- `n`: 元素数，类型为 `size_t`。
- 输出：float32 标量。
- 当 `n == 0` 时结果为 `0.0f`；此时 `x` 可以为空。
- 当 `n > 0` 且 `x == nullptr` 时，CPU API 抛出 `std::invalid_argument`。
- 输入值遵循 IEEE 754 float32。NaN/Inf 按浮点加法传播；不提供忽略 NaN 的模式。

## Dtype 与 shape

- 第一版只支持 float32。
- 逻辑 shape 为 `[n]`，`n` 可为零。
- 多维输入由调用方展平；步长和非连续视图不在本版范围内。

## 数值精度

CPU 参考实现以 double 累加，再转换为 float32，以便提供稳定的比较基线。并行后端可使用不同归约树，结果不要求逐位相同；有限输入的测试按 `abs(actual - expected) <= 1e-5 + 1e-5 * abs(expected)` 验收。对于极大规模或病态抵消输入，应用应考虑 float32 输出舍入误差。CPU null-pointer 错误语义与设备 API 错误码可按各后端调用约定表达。

## 边界与错误

空输入返回零。非空空指针是调用错误。调用方必须提供至少 `n` 个可读元素；本 API 不探测缓冲区长度。设备后端的指针必须满足该后端的内存类型要求。输出缓冲区与输入不得发生会破坏读取的别名，除非具体后端文档明确支持。

## 验收标准

- CPU 测试覆盖空输入、单元素、常规正负数、空指针和较大输入。
- CPU-only 配置关闭 CUDA/CANN 探测，并可以单独构建参考库与测试。
- CUDA 与 Ascend C 选项互不隐式开启；缺少依赖或实现时给出明确失败/跳过原因。
- 示例确实调用 `reduce_sum`；benchmark 只记录实际运行测量和环境元数据。
- 元数据与文档后端状态一致。
