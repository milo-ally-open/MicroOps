# reduce_sum 提案

## 目标

提供一个语义简单、可逐步优化的求和归约算子，作为学习 CUDA 与 Ascend C 并行分工、内存访问、归约和数值误差的起点，同时示范可测试、可构建和可打包的算子目录结构。

## 动机

求和归约是归约类并行计算的基础。一个小而明确的算子便于对照 CPU 参考实现检查设备结果，也能让后续优化围绕数据分块、线程协作和精度展开。

## 范围

- 第一版输入为连续的一维 float32 数组，输出一个 float32 总和。
- 建立 CPU 参考实现和测试。
- 建立 CUDA、Ascend C 后端目录及独立构建入口，并诚实记录未验证状态。
- 提供灰度像素均值 demo、benchmark 接口和按后端选择的源码包。

## 不包含

- 多轴张量归约、掩码、加权求和、整型/半精度输入和自动微分。
- 未验证设备实现的性能承诺或加速比。
- 在本提案中强制选定 GPU/NPU SDK 版本、设备型号或发布许可证。
