# sub 提案

## 目标

实现连续一维 float32 向量逐元素减法：`C[i] = A[i] - B[i]`。工程结构沿用 `add`，提供 CUDA/CANN v1 基线、v2 候选、host launch、独立设备测试工程和 demo。

## 动机

在已有逐元素加法基础上练习改变算术操作时保持线程索引、内存访问、尾部处理、host 调度和评测流程一致，并观察算术语义对正确性和性能评测的影响。

## 范围

- 连续一维 float32 输入/输出；不支持 stride、广播或重叠别名。
- CUDA v1 一线程处理一个元素；v2 采用对齐 float4 路径、未对齐标量回退和尾部处理。
- CANN v1 使用 grid-stride 逐元素计算；v2 每轮展开四个标量计算。
- CUDA 与 CANN 各有独立 build、correctness、内存评估、benchmark 和 demo 入口。
- 当前所有新后端源文件均为 scaffold，未构建、未在设备上运行，也没有性能记录。

## 不包含

- CPU 算子后端、张量框架集成、广播/步长、多维语义、自动调优或融合。
- 未经真实工具链和设备验证而声称后端可用或 v2 更快。
