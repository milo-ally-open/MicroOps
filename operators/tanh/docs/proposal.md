# tanh 提案

## 目标

提供 float32 连续一维张量的逐元素 Hyperbolic tangent activation，并用 CUDA/CANN v1 标量基线和 v2 四元素展开候选学习设备端并行映射。

## 动机

激活函数是神经网络的常见逐元素算子。此样例练习一元输入、数学函数、精度验证与设备内存/性能测量。

## 范围

- CUDA 与 CANN 独立 kernel、host wrapper、测试工程、内存评估、benchmark 和 demo。
- float32 连续一维输入；多维张量由调用方展平。
- v1 每个线程/迭代处理一个元素；v2 每个线程循环展开处理四个元素并保护尾部。
- 采用 spec.md 中规定的数学近似、非法参数行为和数值验收标准。

## 不包含

- CPU 算子后端、广播/stride、多 dtype、融合、自动调优。
- 未运行工具链或设备验证时声称后端可用或有性能收益。
