# add 提案

## 目标

建立仓库的第一个 CUDA 算子，从 `C[i] = A[i] + B[i]` 展示线程索引、边界保护和 kernel launch。项目以 CUDA/CANN 设备实现为交付目标，不维护 CPU 算子实现。

## 动机

向量加法足够小，便于理解线程到数据的映射，也能作为后续学习内存访问、融合和带宽评估的入门算子。

## 范围

- 连续一维 float32 输入与输出。
- CUDA v1 作为标量基线，每线程处理一个元素。
- CUDA v2 作为向量化候选，对齐时每线程处理四个元素，并保留未对齐回退和尾部处理。
- 建立 CUDA 独立测试工程，覆盖正确性、显存资源和性能评估。
- 建立针对首个实验板卡的 CANN v1 标量 kernel、ACL host 调度及独立测试入口；不把该版本宣称为跨 SoC 优化实现。

## 不包含

- CPU 算子后端或 CPU benchmark。
- 多维、步长、广播、原地别名、自动调优和融合算子。
- 未经实际基准验证就宣称 v2 比 v1 更快。
- 在工具链或设备不可用时宣称后端构建、测试或性能评估成功。
